トラブルシューティング

Kashiwazaki SEO Hamburger Menu の使用中に発生する可能性のある問題と解決方法をまとめています。

ハンバーガーメニューが表示されない

原因 対処法
ブレークポイント設定が画面幅より小さい 設定画面でブレークポイントの値を確認し、対象デバイスの画面幅に合わせて調整してください
プラグインが有効化されていない 管理画面の プラグイン 一覧で Kashiwazaki SEO Hamburger Menu が有効になっていることを確認してください
テーマの CSS との競合 ブラウザの開発者ツールで要素を検証し、テーマの CSS がハンバーガーメニューの表示を上書きしていないか確認してください
JavaScript エラー ブラウザの開発者ツールのコンソールでエラーがないか確認してください。他のプラグインやテーマの JavaScript と競合している可能性があります

メニュー項目が表示されない

原因 対処法
メニューソースが未設定 設定画面で WordPress メニューの選択、またはカスタムメニュー項目の追加を行ってください
選択した WordPress メニューが削除されている 外観 > メニュー で対象メニューが存在するか確認し、必要に応じて再選択してください

カラー設定が反映されない

1

設定画面で 設定を保存 をクリックしたか確認してください。

2

ブラウザのキャッシュをクリアしてページを再読み込みしてください。Ctrl + Shift + R（Mac: Cmd + Shift + R）でスーパーリロードが可能です。

3

キャッシュプラグイン（WP Super Cache、W3 Total Cache など）を使用している場合は、キャッシュをパージしてください。

ヒント

テーマやカスタム CSS で !important が使用されている場合、プラグインのカラー設定が上書きされる可能性があります。ブラウザの開発者ツールで優先順位を確認してください。

構造化データが出力されない

原因 対処法
メニュー項目が未設定 メニュー項目が1つ以上設定されていることを確認してください。空のメニューでは構造化データは出力されません
キャッシュが残っている キャッシュプラグインのキャッシュをクリアし、ページのソースコードで JSON-LD の出力を確認してください
構造化データの確認方法

ページのソースコード（Ctrl + U）を表示し、SiteNavigationElement で検索してください。または、Google のリッチリザルトテストツールで確認できます。

他のプラグインとの競合

他のプラグインとの競合が疑われる場合は、以下の手順で切り分けを行ってください。

1

Kashiwazaki SEO Hamburger Menu 以外のプラグインをすべて無効化します。

2

問題が解消するか確認します。解消した場合は、プラグインを1つずつ有効化して競合の原因を特定します。

3

テーマの切り替えも試してください。デフォルトテーマ（Twenty Twenty-Five など）に切り替えることで、テーマ側の問題かどうかを判別できます。

注意

プラグインの無効化やテーマの切り替えは、本番環境ではなくステージング環境で行うことを推奨します。

設定画面にアクセスできない

設定画面が表示されない、または「権限がありません」と表示される場合は、ログイン中のアカウントに manage_options 権限（管理者権限）があることを確認してください。編集者や投稿者の権限ではアクセスできません。
